# Entra ID Identity Detector

**Status:** In progress; identity-layer detection lab, extension of [SecureBank (AWS)](https://github.com/fadhilkhafiz31/aws-bruteforce-splunk)

Detecting brute-force and impossible-travel sign-in patterns in Microsoft Entra ID using Conditional Access, Identity Protection, and KQL. Companion project to SecureBank, which covers IaaS/network-layer detection on AWS. This one covers SaaS/PaaS identity-layer detection on Azure
